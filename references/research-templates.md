# 深度研究模板

仅在需要拟定研究方案、组织工作包或写判断稿时读取。取证仍走 `argo_research`。

## A. 研究契约

```markdown
# 研究契约

- **决策/用途**：
- **核心问题**：
- **工作包**：
- **范围**：对象、地域、时间窗、纳入与排除。
- **时效性**：资料截点。
- **用户资料**：标为「用户提供」，不与公开证据混称。
- **停止条件**：覆盖、交叉验证、信息饱和的可检查标准。
```

## B. 工作包

```json
{
  "id": "wp-1",
  "question": "待回答的可验证问题",
  "query": "可选检索词，缺省用 question",
  "priority_sources": [],
  "depends_on": []
}
```

## C. 判断稿骨架

```markdown
# [主题] 研究判断

> 研究截点：YYYY-MM-DD。取证包见 dossier。本文区分事实 / 推断 / 建议。

## 执行摘要
直接回答核心问题，写结论强度和关键限制。

## 研究问题与边界

## 关键发现
### 发现一
事实：… [n]
推断：…

## 结论与建议
建议：…（条件、权衡、下一步核验）

## 局限与未解
```
