# 约定：
#   1. 条目每行一个 tests/test_*.py，保持排序（减少 diff 冲突）；
#   2. 新门禁测试的文件名遵循门禁命名约定（含 gate/consistency/drift/
#      snapshot/registry/contract/sync/lint 之一），漏册会被
#      test_gate_manifest.py 直接拦下；
#   3. 不进快门禁的门禁类测试在此登记一行豁免：
#         # skip tests/test_xxx.py <理由>
#      豁免指向已删除的文件同样会被门禁拦下（防死行累积）；
#   4. 纳入门槛：单文件 <1s 且属提交期高频回归；慢项/发版场景/CI 元门禁
#      一律豁免（CI 全量切片兜底）。
