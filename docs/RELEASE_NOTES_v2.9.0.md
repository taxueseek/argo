# RELEASE_NOTES_v2.9.0

相对 v2.8.9 的 62 个提交，一句话总览：**搜索源优化——新增 16 个源、替换部分质量不佳的源，净 237 → 253（免配置 198 → 219）；两个常青源修活；插件与 CLI 搜索能力首次完全持平（19 个 MCP 工具）；多语言小语种源 +14 并按语言自动配源；本地使用日志规范化（仅本机）并新增 `argo stats` 读出口；74 个功能开关成表可查。** 测试从 2365 个测试函数增至 2770+（全量 3082 通过），本发布包经密钥泄漏扫描，零命中。

## 搜索源：先提质，再控量（237 → 253，免配置 198 → 219）

- **新增**：14 个小语种本地新闻源、CORE 开放获取全文源、iPlant 植物智（中文植物名 → 学名+分类，补上「从中文俗名进生物数据库」的空白）、sov2ex 全文搜索（实测 48ms）、TinEye 反搜图、Bing RSS 稳定出口、Exa 免 key 匿名通道；PubMed 此前静默失效，已修复。
- **替换部分质量不佳的源**：逐源按「结果质量、稳定性、可验证性」实测评估，未达标的源不再随版发布，腾出的预算位让给可用性更好的源。**原则：宁少勿死——源贵在每一条都能交付。**
- **两个常青源修活**：百度与搜狗的历史低产真根因是「结果链接全是跳转壳、被聚合层整批滤掉」——现在引擎层逐条解析跳转链换真实 URL，并优化了连接身份管理。百度实测单次可稳定产出。
- **出处可验证**：npm 引擎与技能目录源补齐发布时间与可验证出处链接。

## 多语言：小语种不再二等

- 新增 14 个本地语言新闻源（日/韩/俄/西/法德意之外的小语种：泰/阿拉伯/希伯来/希腊/印地/越南/土耳其/印尼等）。
- **语言绑定选源**：按查询语言自动配「该语言真正可用」的源；非拉丁语查询由 local_bing 动态 setlang 承接多语言索引；被语言门剔除的引擎在输出的 `noise_dropped` 里可见——「为什么少了几个源」有账可查。
- 日语零结果兜底、语言软排序数据驱动、多语言评估池同步更新。

## 插件与 CLI 搜索能力持平（19 个 MCP 工具）

- CLI 18 个命令与 MCP 19 个工具一一对应，本轮补齐 `argo_extract`（结构化提取）、`argo_preflight`（批量 URL 预检）、`argo_answer`（带引用直答）、`argo_watch`（网页变化监控）、`argo_cite`（DOI 四格式引用条目）。
- 一致性由门禁锁定：CLI 能力命令 ↔ 工具一一映射、文案计数与真源相等——「插件又落后了」这类漂移从此测试就红。
- DSH 插件三形态接入不变：原生工具默认入口（零常驻 token）、web_search seam、按需挂载 MCP（19 工具 ≈3.7K token/轮；默认只挂核心三件 ≈919 token）。

## 性能：上一轮「冷启动 0.85s→0.16s」的同根因延续

- 导入链 252ms → 35ms（−79%）：网络栈延迟导入全链收口；路由热路径再去掉 25 个模块的连带加载。
- 重排序 K 相关剪枝：n=200 场景 33ms → 1.5ms；查询理解固定开销每查询再省 6-7ms。
- 缓存键修正：从按「回答」算改回按「请求」算，命中率从六成到基本不 miss。
- 深度研究整链墙钟 −28%（扩词层去掉不产生新信息的变体，消融实验驱动）。

## 更可信（修复精选，全部带测试）

- 早停被弃置的结果不再被误标成「超时」毒化自适应学习器（cancelled 分流）。
- 兜底处理器自身缺陷不再让整次搜索崩溃；抓取链 deadline 击穿修复。
- 限定符查询的缓存串味、域规则 32 例实测误判、HTML 假搜索页垃圾结果——各修各的根因。
- 配额写路径跨进程丢数据（CLI/插件/评测三方并行时计数互相覆盖，数据损坏级）：7 处写路径全部补齐跨进程安全。
- `--explain-timing` 的 import_ms 恒为 0（工具报不出自己最大的开销）：实测恢复 20-30ms 真值。

## 规范的本地使用日志（仅本机，不外发）

- 正名：这套机制叫**本地使用日志**（usage_log），不叫遥测——它不出本机，名字必须与信任边界一致。
- 新命令 **`argo stats`**：命中率、平均时延、引擎频次、救援率、最近查询——搜索质量第一次有了自己的账本。
- 四个 JSONL 流（查询总账/救援链/路由采样/融合去重），单流自动回缩（1MB/2000 行），总开关 `ARGO_USAGE_LOG=0`。
- 隐私纪律：query 截断脱敏、仅本机存储、**用量统计不进任何对外材料**。

## 功能开关成表（74 个，一份文档查全）

`references/usage.md` 升级 v2.9.0：18 命令总览、全命令参数、**74 个 `ARGO_*` 开关按六类成表**（能力开关/密钥/行为调参/路径/MCP 运行配置/抓取降级分级），日志与反馈一章讲清「数据在哪、怎么读、怎么关、反馈闭环怎么工作」。文档受四件套门禁锁定——说的能力必真存在，真存在的能力必在文档。

## 安全与脱敏

- 密钥脱敏三形态（URL 查询串嵌的密钥 / 正文里贴的凭证 / 值级递归），唯一实现被失败归因、归档、引擎列表输出三处复用——凭证进不了任何持久化文件。
- 本发布包与仓库经密钥泄漏扫描：本机 12 个真实密钥值逐一比对 + 常见密钥形态（sk-/ghp_/AKIA）全仓扫描，零命中。

## 安装与 DSH 插件支持的版本

- 安装：`npx -y github:taxueseek/argo`，或 `install.sh`；DSH 插件：`dsh plugin --profile web add "github:taxueseek/argo#main&path:packages/dsh-plugin"`。
- **DSH 插件支持的版本**：Node.js ≥ 18；Python 3.10+（`pip install pyyaml`）；DSH 宿主的子代理 provider 需支持 `outputSchema` / `toolFilter` / `depthLimit`（标准 `spawn` 即可）——实测于 DSH 0.1.7-alpha.1。
- 本发布包含打包产物 `argo-search-2.9.0.tgz`（406 个文件，解包 5.0MB，与仓库同源同扫描）。
