# Argo v2.9.8 发布说明

**版本**：2.9.8
**定位**：路由精度审计与反馈闭环。把 v2.9.7 以来积累的分发、质量、重构改动一并收进本版，并集中修掉 issue #18 / #19 暴露的路由与夜间任务问题。

**致谢**：感谢 [@wpp666](https://github.com/wpp666)（王平）在 issue #18 提供的复现环境、查询样本和期望对照。这个 issue 把「有结果但答非所问」的链路讲得很清楚，本版沿着它扩展成了更广泛的路由精度审计。

## 这次更新有什么（通俗版）

### 1. issue #18 的三件事都已复现并修掉

**以前**：

- 查询里出现 `latest` 就被判进实时新闻域，软件版本查询也会走新闻源
- 人民网的模糊搜索匹配不到时，返回整页最新 feed，形态正常但内容无关
- `local_bing` 对「2026年新能源汽车销量数据」只命中「2026」，五条结果全是年表、节假日
- `cross_validation` 对中文查询恒报 `0/N 相关`，这个信号本身不可信

**现在**：

- `latest` 只有在 `latest news / on / about / in` 等明确新闻搭配下才触发实时新闻
- 人民网默认 feed、SERP 缓存页按 query token 覆盖率识别为「答非所问」，整页丢弃并触发恢复链
- `local_bing` 的年份表垃圾页同样被覆盖率门拦下，返回诚实空结果，不再伪装成成功
- `cross_validation` 改用 CJK 二元组覆盖率，真实中文查询能正确报出相关条数

### 2. 顺着同一类问题，审计并收窄了 16 类误触发

用真实查询回放 + 97 个域规则自检，找到的不是一条查询，而是一批同构问题：

- **CJK 构词成分**：品牌名里的「雪」被当天气、产品名里的「火山」被当地理、UI 排障里的「图标」被当找图、图书馆语境里的「馆藏」被当博物馆、电动车里的「动车」被当车票
- **ASCII 子串**：`F1` 命中 `off10/off11`，`Go` 命中 `argo`，`Java` 命中 `JavaScript`
- **跨域同形**：统一社会信用代码/基金代码/商品代码被当代码搜索；代码库语境里的「汇率」被当实时牌价；裸「漏洞」没有域接
- **域缺口**：「降准」没进财经新闻、工商字段没让位给 `company_search`、中国宏观查询让 FRED 领队返回了美国 GDP

修法的共同点是**保留真查询、只排除撞车说法**：每条收窄都配一条误判反例和一条真查询对照，避免把域改废。

### 3. issue #19：nightly 账本不再因为空日志失败

**以前**：全新 runner 没有使用日志，`argo stats` 只返回 `{"samples": 0}`，夜间账本直接读 `avg_elapsed_ms` 就 `KeyError`。

**现在**：`argo stats` 空日志也返回稳定字段形状，指标用 `None` 表示「没有样本」；夜间工作流按 `samples` 判断，没有样本就不喂 benchmark，不画 0ms 假曲线。

### 4. v2.9.7 以来的其他改动也一并收进本版

- **分发**：打通 npm 标准分发与 MCP 客户端矩阵；npm 包瘦身与自愈提示；Release 资产构建与 Windows 镜像回退
- **质量**：内容农场过滤真正接线；跨语言长程溯源；BM25+ 与短语邻近度加权；本地工程意图与文件名精准度
- **重构**：搜索主管线恢复执行器拆出、MCP 压缩/本地沙箱/预热模块化、DSH 插件 wide_research 与执行器连接池拆模块
- **DSH 插件**：运行监控看板、快速预设、配置即时搜索过滤
- **路由**：修三处域冲突；补 53 个零用例域的路由用例，并加「每域至少一条路由用例」门禁

## 验证

- 全量 `python3 -m pytest -q` 退出码 0
- 路由精度、域规则 schema、路由快照、矩阵覆盖、macro/fx 专项全部通过
- 单飞用例连跑 50 次无偶发失败
- 夜间账本用空日志和真实日志分别模拟：空数据 `samples=0, bench=[]`，真实数据正常产出指标
- 真实查询复验：issue #18 的两条查询都从「答非所问」回到相关结果；`央行 降准 最新` 从维基实体回到财经新闻；`国家统计局 一季度 GDP` 从 FRED 美国 GDP 回到 worldbank 中国 GDP
- 路由本身没有变慢：200 条查询平均 1.8ms

## 兼容性

- 无破坏性变更，v2.9.7 的配置与用法继续有效
- 仓库版本号、五语 README、DSH 插件对照表、hero 图标统一到 2.9.8
- 测试态隔离只影响测试：adaptive 与熔断状态按用例使用独立临时库，不再跨用例串味
