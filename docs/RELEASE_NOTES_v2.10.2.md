# Argo v2.10.2 发布说明

**版本**：2.10.2
**定位**：语义路由三步走（P0-P1 相关性锚点加权 + P2 静态概念向量表）与路由准确率收口。标注定向 76.9%→100%，路由快照 61% 决策从 tfidf 打分换概念直判；熔断器工厂模块别名分裂修复；ZCode 面板三页版入库。

---

## 这次更新有什么（通俗版）

### 1. 路由标注定向 76.9%→100%（13 条人工标注集，离线确定性）

此前有两整类「意图撞车」在既有路由门禁里命中数为 0：

- 问原理/详解被送进学术库：「Transformer 模型 原理」「Attention 机制 详解」拿到的是 NLP 综述论文，不是讲解；
- 找平台内容被当成舆情监听：「小红书 露营 攻略」拿到的是营销稿与舆情监测，不是攻略。

本版建立 `test_route_accuracy_labeled` 人工标注集与 `test_route_executability` 可执行性两道新门禁，配合相关性锚点加权（`rank_signals` 相关性算子 V2）、概念路由地名维清零与泛域降权、路由准确率收口与输出装配修正，13 条标注集上域定向与主源族定向双双 13/13（上一版 10/13）。

**A/B 对照（ARGO_ROUTE_CACHE=0，离线纯路由口径，非端到端）**：

| 臂 | 域定向 | 主源族 | 失配 |
|---|---|---|---|
| 上一版 af556a3 | 10/13（76.9%） | 13/13 | 原理→academic、详解→academic、攻略→social |
| 本版默认 | 13/13（100%） | 13/13 | 无 |
| 本版 + `ARGO_CONCEPT_ROUTER=1` | 13/13（100%） | 13/13 | 无 |

路由快照（201 条共有查询）中 123 条（61%）的决策路径从 tfidf 打分换为 regex/概念直判——命中更快、可解释、可断言。

### 2. 零依赖语义路由地基（默认关）

- `backends/engine_concept_vectors.json`（3104 行）+ `concept_vectors.bin` 静态概念向量表入仓，`scripts/build_concept_table.py` 是构建器（612 行），`concept_lookup.py` + `route_primary.py` 是查表与 primary 直判；
- **默认关闭功能的打开方式**：`ARGO_CONCEPT_ROUTER=1` 开启概念语义路由。本版标注集上开/关同分（13/13），它的价值在规则未覆盖查询的泛化，随 badcase 语料积累验证后再评估默认开；
- 相关性算子 V2 默认开，`ARGO_RELEVANCE_V2=0` 可退回旧单字覆盖率口径。

### 3. 熔断器与输出装配收口

- **以前不行**：熔断器工厂按模块路径缓存，同名模块从不同路径二次加载时各自分裂一份状态，熔断记录互不相认；**现在**改调用期解析，模块别名分裂消除（专项回归 `test_circuit_breaker_module_alias` 116 行锁住）；
- 摘要标签卫生 `snippet_clean.py`（剥内联标签与 HTML 实体）与口径去重 `caliber_dedupe.py` 落地，输出装配修正。

### 4. ZCode 面板三页版入库与测试环境加固

- 看板/密钥/诊断三 tab 面板入库（CSS 变量化 + 深色模式），与 10-29 实机验收的插件交付物对齐；
- 测试环境泄漏加固：conftest 新增 `ARGO_*` 环境变量每用例快照恢复层，`test_seek_locator` 补对称 tearDown——堵住「直接写 os.environ 不恢复」的脏值经 subprocess 套件传播（全量偶发红 3 条的顺序彩票形态，修复后 seek 相关 42 项绿）。

## 相关依赖

- 零新依赖：概念向量表是预构建数据文件随仓分发，不需要 model2vec 包；
- 路由快照门禁升级后，改动路由规则需重录 `tests/golden/routing_snapshot.json`（快照诊断已强化，失配时输出更可定位）。
