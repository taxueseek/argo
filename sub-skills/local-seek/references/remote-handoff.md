# 本地搜不到时的交接（remote-handoff）

local-seek 只负责本机。本地无结果不意味着结束，按本清单逐步扩大，最后
交接给联网搜索。判断标准写死在每一步，避免无限折腾。

## 交接顺序（每步只做一次，失败即进下一步）

```text
L1 当前目录 rg 搜索（默认）
  ↓ 无命中
L2 --path 扩大到知识域（~/notes、~/Documents、技能库等）
  ↓ 无命中
L3 --spotlight 全盘兜底（mdfind，走 macOS 索引，覆盖 PDF/邮件/笔记）
  ↓ 无命中
L4 换词重试 1 次（同义词/拆词/去掉修饰词），仍无
  ↓
L5 交接联网：unified-search（多引擎聚合）或 argo（深度研究）
```

## 判断标准

| 现象 | 结论 | 动作 |
|------|------|------|
| L1-L3 均无命中 | 本机确实没有，或不在已索引范围 | 进 L4 |
| 换词后仍无 | 大概率是「没有这个内容」而非「没找到」 | 进 L5 |
| L5 联网也无 | 内容不存在或太新未收录 | 如实告知，停止搜索 |
| 命中但太少/太泛 | 不是交接问题，是词选得不好 | 回到 L2/L4 调整 |

## 交接命令

```bash
# 本地最后一搏
python3 ~/.agents/skills/argo/sub-skills/local-seek/scripts/seek.py "关键词" --spotlight

# 联网：unified-search（多引擎，快）
# 联网：argo 深度研究（学术/金融领域，带信源核验）
```

## 纪律

- **禁止无限扩大**：每层只试一次，最多一轮换词，两轮无果就交接或停止。
- **交接前确认需求边界**：用户要的是「我电脑里的文件」就别接出网；
  要的是「这个事实/最新信息」就该直接联网，不必先搜本地。
- **本地与联网并行**：需求两可时并行调用，互不阻塞，先到的先答。
- **不把联网结果当本地文件**：交接后答案来自网络，措辞上要区分来源，
  需要文件路径的请求不能用网页内容冒充。
